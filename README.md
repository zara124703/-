# رحلة استكشاف منغوليا (Mongolia Exploration Game)

لعبة تعليمية تفاعلية بالعربية (RTL) لطالبات المرحلة الثانوية، من أربع مراحل: التاريخ، المعالم، الثقافة، الطبيعة.

## الملفات
- `index.html` الصفحة
- `style.css` التصميم
- `script.js` منطق اللعبة والنقاط

## النشر على GitHub Pages
1. أنشئي مستودعًا جديدًا على GitHub (Public).
2. ارفعي الملفات الأربعة إلى جذر المستودع.
3. من Settings ثم Pages: اختاري Branch = main والمجلد = / (root) ثم Save.
4. بعد دقيقة تقريبًا يظهر الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`
